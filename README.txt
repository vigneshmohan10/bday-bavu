BAVU & VICKY — PERSONALIZED BIRTHDAY WEBSITE
=============================================

Built with plain HTML, CSS, and vanilla JavaScript. No frameworks.

Includes:
- Mobile-responsive lavender/purple design
- 35 real photos, including HEIC photos converted to browser-compatible JPG
- Gallery filters: All memories, Bavu, Us together, Little memories
- Full-screen photo viewer with previous/next, Escape, and arrow-key controls
- Personalized LinkedIn-to-love-story timeline and letters
- Animated purple cake, candle interactions, secret promise, and bucket list
- Background music with looping playback and a single mute/unmute button

Run locally:
1. Extract the ZIP.
2. Open index.html in your browser, or use VS Code Live Server.

Music:
The included audio at assets/music/our-song.mp3 is set to autoplay and loop. Browsers may block audible autoplay; in that case, the audio attempts to start muted and the single speaker button can unmute it. A visitor interaction may still be required by some browsers.

Photo notes:
The assets/photos folder contains optimized copies of the 35 uploaded photos. The original uploaded archive is not modified. If you want different photos assigned to a category, update PHOTO_MEMORIES in script.js.

Deploy:
Upload this folder to a static host such as GitHub Pages or Netlify. Anyone who can access the public website can view and save its photos; use access controls if you want it restricted.

Recent personalization: the landing page now features Bavu as a little child (photo-30.jpg); the promise/secret section has been removed; future dreams are displayed as simple romantic points instead of a checklist.
